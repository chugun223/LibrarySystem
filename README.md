Library System

Практическая работа №8

В работе реализованы:
модульное тестирование бизнес логики
интеграционное тестирование rest api
ui тестирование веб-приложения с помощью Selenium

Для модульного тестирования использованы JUnit5 и mockito.
Реализованы тесты для ReportServiceImpl, которые проверяют работу бизнес логики сервиса отчётов

Всего реализовано 6 тестов:
createReportSuccess проверяет создание отчёта, его сохранение в репозитории и возврат id
getReportSuccess проверяет получение отчёта по id, если он существует
getReportNull проверяет поведение сервиса при запросе несуществующего отчёта
generateReportAsyncSuccess проверяет успешную генерацию отчёта
generateReportAsyncError проверяет обработку ошибки при генерации отчёта
generateReportAsyncNotExists проверяет, что при отсутствии отчёта сервис не выполняет дальнейшую обработку

Интеграционное тестирование REST API
Для проверки REST API использована библиотека REST Assured. Тесты проверяют взаимодействие с ReportController и корректность http ответов

реализованы следующие сценарии:
создание отчёта
получение завершённого отчёта
получение отчёта в процессе создания
получение отчёта с ошибкой
получение несуществующего отчёта

Для интеграционных тестов создан отдельный класс TestSecurityConfig.
В нём собственная цепочка фильтров Spring Security, которая разрешает все запросы без авторизации и применяется только к маршрутам /reports/**

UI-тестирование с помощью Selenium
Реализован сценарий проверки авторизации пользователя и выхода из системы

Последовательность действий:
открытие страницы авторизации
ввод email ivanov@example.com
ввод пароля password
нажатие кнопки входа
проверка перехода на страницу списка книг
проверка наличия таблицы с книгами и её заголовков
проверка наличия записей в таблице
нажатие кнопки Logout
проверка возврата на страницу авторизации

В шаблон bookList.html добавлена кнопка выхода из системы, отправляющая POST-запрос на /logout


Проверка тестов
Нужно создать файл .env. Его можно скопировать из .env.example После этого нужно выполнить в консоли команду: docker-compose up -d которая поднимет контейнер с PostgreSQL.

Для запуска всех тестов через Maven необходимо выполнить командув терминале:
mvn test
Для запуска тестов из intellij надо открыть src/test/java, выбрать нужный тест и запустить его
