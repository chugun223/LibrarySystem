Практическая работа №6

В проект была добавлена система аутентификации и авторизации на базе Spring Security.

В сущность User были добавлены два новых поля:
password для хранения хеша пароля
role для хранения роли пользователя

Создан enum Role с двумя значениями USER и ADMIN. В Liquibase-миграции create-users.xml добавлены соответствующие колонки. В миграцию с тестовыми данными добавлены пароли и роли для всех тестовых пользователей(пароль для всех тестовых пользователей задан 'password').

В pom.xml добавлена зависимость spring-boot-starter-security

Создан класс UserDetailsServiceImpl, который реализует UserDetailsService
В методе loadUserByUsername:
Ищет пользователя в БД по email
Преобразует его роль в GrantedAuthority
Возвращает объект UserDetails из Spring Security

Создан класс конфигурации, в нем:
Объявлен бин PasswordEncoder
Объявлен бин SecurityFilterChain, в котором настроены правила доступа:
    Пути /login и /registration доступны всем
    Swagger UI(/swagger-ui/) доступен только роли ADMIN
    Любые изменяющие запросы (POST, PUT, PATCH, DELETE) доступны только роли ADMIN (обычные пользователи могут только просматривать книги, авторов и жанры)
    Все остальные запросы требуют аутентификации
Настроена кастомная форма логина (страница /login)
Настроен выход из системы по пути /logout.

Создан LoginController и HTML-шаблон login.html. Форма отправляет данные на POST /login

Реализована регистрация новых пользователей:
Создан RegistrationController, который обрабатывает GET /registration (показ формы) и POST /registration
Создан DTO RegistrationDto для приема данных из формы.
Создан HTML-шаблон registration.html
При регистрации пароль хешируется через PasswordEncoder, а роль по умолчанию устанавливается USER
Если пользователь с таким email уже существует выводится сообщение об ошибке
После успешной регистрации происходит редирект на страницу логина


Проврека

Запустить приложение
Для запуска приложения сначала нужно создать файл .env. Его можно скопировать из .env.example
После этого нужно выполнить в консоли команду: docker-compose up -d которая поднимет контейнер с PostgreSQL.
Затем можно запустить само приложение.

Перейти по адресу http://localhost:8080/books Так как вы не авторизованы, то произойдет редирект на страницу логина http://localhost:8080/login
Войти под учетной записью администратора ivanov@example.com / password
    После входа произойдет редирект на список книг /view/books/list
    Попробуйте открыть Swagger UI http://localhost:8080/swagger-ui.html он должен открыться.

Выйдите из системы перейдя по пути http://localhost:8080/logout
Войти под учетной записью обычного пользователя petrov@example.com / password
    Попробуйте открыть Swagger UI вы получите ошибку
    Попробуйте создать книгу или удалить пользователя через API
Перейдите на страницу регистрации http://localhost:8080/registration
    Заполните форму новыми данными
    После успешной регистрации вы будете перенаправлены на страницу логина
    Войдите с новыми учетными данными. Новый пользователь получит роль USER
