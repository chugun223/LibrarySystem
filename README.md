Практическая работа №6

В проект добавлена возможность формировать html отчёт со статистикой. Отчёт создаётся по rest запросу генерируется в фоне, а потом его можно получить по id

Создана новая сущность Report для хранения отчётов:
id
status статус отчёта
content содержимое отчёта

Создан enum ReportStatus с тремя значениями:
CREATED COMPLETED ERROR

Создан репозиторий ReportRepository

Создана миграция create-reports.xml, которая создаёт таблицу reports с колонками id, status, content.


Создан интерфейс ReportService и его реализация ReportServiceImpl. В сервисе реализованы методы:
createReport создаёт отчёт со статусом CREATED в БД и возвращает его id
getReport возвращает отчёт по id
generateReportAsync асинхронный метод формирования отчёта

Асинхронность через CompletableFuture.runAsync() по методичке. Внутри метода запускаются два потока:
Thread 1 считает количество зарегистрированных пользователей
Thread 2 получает список книг

Оба потока работают параллельно, главный ждёт их завершения через join. Время каждого потока замеряется внутри самого потока

Создан ReportController с двумя эндпоинтами:
POST /reports создаёт отчёт и запускает его формирование, сразу возвращает {"reportId": } и не ждёт окончания генерации
GET /reports/{id} возвращает содержимое отчёта по id. В зависимости от статуса:
COMPLETED - готовый HTML
CREATED - Отчёт ещё формируется
ERROR - сообщение об ошибке (500);
отчёта нет - 404

Создан Thymeleaf-шаблон report.html, который содержит:
количество пользователей и время его подсчёта
таблицу книг и время получения списка
общее время формирования отчёта

Изменения в SecurityConfig
В SecurityConfig отключён CSRF, иначе POST /reports через postman отклоняется

Проверка через postman

Для запуска приложения сначала нужно создать файл .env. Его можно скопировать из .env.example После этого нужно выполнить в консоли команду: docker-compose up -d которая поднимет контейнер с PostgreSQL. Затем можно запустить само приложение.

Далее создать новый отчет в Postman:

метод: POST
url: http://localhost:8080/reports
authorization: тип Basic Auth, вводим данные админа из тестовых данных: логин ivanov@example.com пароль password

в теле ответа вернется id созданного отчета


Получение готового отчёта

метод: GET
url: http://localhost:8080/reports/{id отчета}
authorization: Basic Auth

должно вернуться 200 OK и html страница отчета
